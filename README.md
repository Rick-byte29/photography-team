# Aura Studios

Premium photography homepage built with Next.js, Tailwind CSS and Framer Motion.

## Run

```sh
npm install
npm run dev
```

## Production / Vercel

Import this repository into Vercel and choose Next.js. The build command is `npm run build`; leave the output directory at the framework default. No environment variables are required.

```sh
npm run typecheck
npm run build
npm start
```

## Features

- Cinematic muted Indian wedding video with poster fallback and pause control
- Responsive filterable masonry portfolio and lightbox
- Swipeable 3D carousel, scroll effects and reduced-motion handling
- Three-step package, date/time and contact form
- WhatsApp enquiries to +91 9101035255, with prefilled booking details and a sticky CTA
- Embedded Bongaigaon city map and accessible privacy-policy dialog

WhatsApp opens a draft. Visitors must review it and tap Send; this does not reserve a date. Sample prices and testimonials should be replaced before business launch. The map shows the city, not a verified studio street address. Portfolio images and video use verified Pexels URLs; see ASSETS.md. The hosted edition bundles those media locally. No personal data is submitted to a server database.
